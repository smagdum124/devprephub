# 🚀 DevPrepHub

DevPrepHub is a modern developer interview preparation platform built with React, Node.js, Express, and MongoDB.

🌐 Live Website:
https://devprephub-nine.vercel.app

## ✨ Features

- 💻 500+ Interview Questions
- 🗺️ Developer Roadmaps
- 📝 Resume Tips
- 📚 Developer Blogs
- 🔍 Search & Category Filter
- 📄 SEO Optimized Pages
- 📱 Responsive Design
- 🌙 Dark / Light Mode
- 🔐 Admin Dashboard
- 📬 Contact Form
- 📈 Google Analytics Integration

## 🛠 Tech Stack

Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios
- Framer Motion

Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
